Setup Firebase

Noteworthy is 100% serverless. To run it locally or on GitHub Pages, you need to connect your own Firebase project.
  1. Go to Firebase Console and create a project.
  2. Enable Email/Password Authentication under Build -> Authentication.
  3. Enable Cloud Firestore under Build -> Firestore Database.
  4. Create a Web App in your project settings, and paste the firebaseConfig JS object below.

Notebook maintenance

One-off jobs that tidy the notebook behind the app. They are safe to re-run and they never rewrite your notes.

Import old connections Copies connections written into your older notes into the graph. Run once.
Build the graph Embeds and links every note that predates connections. Resumable.
File notes into concepts Concepts only ever got attached at capture. Files the backlog into one shared vocabulary, in batches.
Re-draw connections Runs linking again against the semantic index. The first pass had no vectors to choose candidates from. One model call per note, and it adds to what is already there rather than replacing it.
Consolidate profile Merges duplicate signals about you into one clean profile.
Suggest collections Proposes groupings for unfiled notes instead of filing them by hand.
